# 🚀 Focus Academy — Aulas de Front-End (React.js + Tailwind CSS)

Repositório dedicado aos códigos, exercícios e projetos desenvolvidos durante as aulas práticas de **Desenvolvimento Front-End** na **Focus Academy**. O objetivo é guiar iniciantes desde os primeiros passos com React até a construção de interfaces modernas, componentizadas e responsivas.

---

## 📂 Estrutura do Repositório

O repositório está dividido por aulas e projetos práticos:

* 📁 **`FocusAcademy-aula1/`** — Introdução ao React.js: estrutura inicial com Vite, sintaxe JSX, regra de nomenclatura de tags (HTML vs. Componentes React) e criação dos primeiros componentes.
* 📁 **`CafeRaizes/`** — Projeto prático de Landing Page para uma cafeteria artesanal, aplicando organização de arquitetura (`pages/` e `components/`), estilização com Tailwind CSS e reutilização de componentes via **Props**.

---

## 🛠️ Tecnologias Utilizadas

* **[React.js](https://pt-br.react.dev/)** — Biblioteca JavaScript para construção de interfaces baseadas em componentes.
* **[Vite](https://vite.dev/)** — Ferramenta de build rápida para o ambiente de desenvolvimento.
* **[Tailwind CSS](https://tailwindcss.com/)** — Framework CSS utilitário para estilização ágil diretamente no JSX.
